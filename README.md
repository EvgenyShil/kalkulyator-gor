# Калькулятор гор

Калькулятор бюджета горнолыжной поездки из Москвы: Шерегеш, Кировск, Сочи (Красная Поляна), Эльбрус, плюс вкладка сравнения.
Прод: https://kalkulyator-sheregesha.vercel.app (Vercel, проект `kalkulyator-sheregesha`). Push в `main` = деплой на прод.

## Структура
- `index.html` — вся страница (HTML + CSS + JS, без сборки). Настройки курортов — объект `RES`:
  аэропорт, авиакомпании, доплаты за багаж, сезон (`open`/`close`, точки оценки `snow`), цены по умолчанию.
  Всё, что помечено на странице «примерно», — оценки, их стоит уточнять.
- `api/prices.js` — прокси к ленте цен Aviasales. `GET /api/prices?dest=NOZ|KVK|AER|MRV&from=&to=&tmin=&tmax=`.
  Только прямые рейсы, по каждой авиакомпании отдельно (лента не отдаёт авиакомпанию). Без кэша.
- `api/saves.js` — общие сохранённые расчёты в Vercel Blob (`saves/*.json`). Сохраняется весь расчёт (все курорты).
  Старые сохранения (только Шерегеш) открываются через `migrate()` в index.html.

## Логика
- Галка «Общие даты»: окно дат, длина поездки и выбранный перелёт общие; остальные поля у каждого курорта свои.
- Галка «С женой»: всё на человека × 2, номер целиком на вас. Такси и трансфер «за машину» — до 4 человек в машине.
- Полоска сезона: оценка снега 0–1 (красный → зелёный); у Кировска ещё световой день (считается по широте).
- «Когда платить»: сейчас (билеты + предоплата отеля), при заселении, на месте, при отъезде.
